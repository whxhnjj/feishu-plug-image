# 🍌 Nano Banana 智能商品图生成器 = 飞鱼 AI 生图助手

&gt; **技术栈**：Vue 3 + Vite 驱动的高性能AI图像生成引擎  
&gt; **核心优势**：基于现代化前端架构，实现2分钟极速出图体验

---

## 🚀 技术架构

### 前端技术栈
- **框架**: Vue 3 (Composition API)
- **构建工具**: Vite 4.x (极速热更新，秒级构建)
- **UI 组件库**: @arco-design/web-vue
- **状态管理**: Pinia (轻量级，TypeScript 友好)

---

## ⚡ 性能优势

得益于 **Vue 3 + Vite** 的现代化架构：

| 特性 | 传统方案 | Nano Banana |
|------|---------|-------------|
| **首屏加载** | 慢 (Webpack 打包) | ⚡ 极速 (Vite 按需编译) |
| **热更新 (HMR)** | 数秒延迟 | ⚡ 毫秒级响应 |
| **构建速度** | 分钟级 | ⚡ 秒级完成 |

## 🛠️ 开发者快速开始

```bash
# 克隆项目
git clone https://github.com/whxhnjj/feishu-plug-image.git

# 进入目录
cd feishu-plug-image

# 安装依赖 (使用 npm 体验最佳)
npm install

# 启动开发服务器 (Vite 热更新)
npm run dev

# 构建生产环境
npm run build:pro
